# Checklist para subir a GitHub

## Antes de hacer push:

- [x] Proyecto compilado sin errores
- [x] .gitignore configurado
- [x] package.json actualizado
- [x] Responsive design implementado
- [ ] Actualizar README.md con descripción real
- [ ] Configurar Git user.name y user.email
- [ ] Hacer commit de cambios
- [ ] Crear repositorio en GitHub
- [ ] Agregar remote origin
- [ ] Hacer push a main

## Comandos para ejecutar:

```bash
# Configurar Git (una sola vez)
git config --global user.name "Tu Nombre"
git config --global user.email "tu@email.com"

# Ver estado de cambios
git status

# Agregar todos los cambios
git add .

# Hacer commit
git commit -m "Initial commit: PES Torneos app"

# Ver remotes
git remote -v

# Agregar remote (si no existe)
git remote add origin https://github.com/TU_USUARIO/pestorneos.git

# Hacer push
git branch -M main
git push -u origin main
```

## Info del Proyecto

- **Nombre**: PES Torneos
- **Descripción**: App web para gestionar torneos de fútbol (PES) con amigos
- **Stack**: Next.js 16, React 19, TypeScript, Tailwind CSS
- **Responsive**: Optimizado para móviles (iPhone, Android)

- `src/app/page.tsx` - Componente principal
